## Data source
Inside Airbnb, Los Angeles: detailed listings for the March 16, 2026 and June 15, 2026 snapshots,
downloaded October 2, 2026. Save them as:
- data/raw/listings_2026-03-16.csv
- data/raw/listings_2026-06-15.csv

Raw files (~120 MB each) are not committed (see .gitignore).

## Run
pip install -r requirements.txt
python scripts/clean_listings.py
python scripts/clean_listings.py --verify-reproducibility   # optional check

## Expected outputs (data/clean/)
- listings_clean.csv: 89,839 rows; not committed (111.7 MB), regenerated by the script
- listings_sample.csv: 50 difficult-case rows
- validation_report.json
- data_dictionary.md
